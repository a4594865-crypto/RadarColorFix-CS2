# RadarColorFix

This simple plugin solves the problem of having more than one player with a color in the same team.

> Currently it is only functional for servers that have a maximum of five players per team.

---

## Installation

1. Install [CounterStrike Sharp](https://github.com/roflmuffin/CounterStrikeSharp) and [Metamod:Source](https://www.sourcemm.net/downloads.php/?branch=master).

2. Download [RadarColorFix.zip](https://github.com/wiruwiru/RadarColorFix-CS2/releases/latest) from the releases section.

3. Unzip the archive and upload it to your CS2 game server.

4. Start the server. The plugin will be loaded and ready to use.

---

## Configuration

The `RadarColorFix.json` configuration file will be automatically generated when the plugin is first loaded. Below are the available configuration options:

| Parameter              | Description                                                                                       | Default              |
|------------------------|---------------------------------------------------------------------------------------------------|----------------------|
| `EnableDebug`          | If enabled (`true`), it will display debug messages in the server console.                              | `false`              |
